# Source guide

Use this guide only when the user has not supplied enough material for the requested lesson or when current exam-format verification is needed.

## Preferred public sources

- IELTS official Academic sample tasks: https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test
- IELTS official Academic Reading format: https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading
- ETS TOEFL iBT preparation resources: https://www.ets.org/toefl/test-takers/ibt/prepare.html
- ETS TOEFL resources for teachers: https://www.ets.org/toefl/teachers-advisors-agents/ibt/teaching.html
- ETS current TOEFL iBT content and structure: https://www.ets.org/toefl/test-takers/ibt/about/content.html
- NASA Space Place for upper-primary science reading and visual background: https://spaceplace.nasa.gov/
- British Council LearnEnglish Kids for public learning activities: https://learnenglishkids.britishcouncil.org/

Useful private-development samples include British Council LearnEnglish Kids “The solar system,” IELTS Academic Reading “development of rockets,” and the updated ETS teacher-practice passage “Aqueducts.” Use official links for testing, but build public portfolio screenshots from original parallel material unless the license clearly permits redistribution.

Prefer the test owner's current pages to coaching blogs when explaining an exam. Record the page title, URL, and access date in `teaching-blueprint.md`.

## Copyright boundary

Public access does not automatically mean free redistribution. Link to official practice material and transform only what is necessary for the user's lesson. For portfolio screenshots, use original material, government/public-domain material, authorized material, or a brief attributed excerpt.

Do not locate full New Concept English lessons or commercial school textbook scans from unofficial download sites. Ask the user to upload the relevant pages, then work within those supplied pages.

## Original fallback material

If no suitable source can be used legally, write an original passage at the requested level and label it “teacher-created practice material”. Do not imitate a named commercial textbook passage closely or claim that an original item is an official IELTS/TOEFL question.
