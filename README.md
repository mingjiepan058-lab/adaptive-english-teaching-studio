# Adaptive English Teaching Studio

面向英语教师的智能备课 Skill。输入教材、题目、学生学段和学习情况后，可按需生成教师逐字稿、课堂教学 PPT、课堂练习，以及课后作业与答案。

适用于小学、初中、高中、四六级、雅思和托福教学。Skill 会分析文章主题、核心词汇、固定搭配、语法知识、长难句和阅读重点，并根据学生水平调整讲解难度与练习形式。

## 主要能力

- 生成带时间安排、讲解话术、课堂提问、预期回答和提示方法的教师逐字稿
- 规划包含英文原文、逐段翻译、词汇语法和互动任务的教学 PPT
- 设计词汇、拼写、搭配、阅读理解、证据定位和句型表达练习
- 生成与课堂目标一致的课后作业及教师答案
- 支持线上一对一、系统讲解型课堂

## 使用方式

将本仓库作为 Codex Skill 安装或复制到个人 Skills 目录。调用时提供：

1. 具体学段
2. 教材或题目
3. 学生情况与课时
4. 需要生成的成品

Skill 入口文件为 [`SKILL.md`](./SKILL.md)。
